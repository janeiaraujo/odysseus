# App Android

O app fica em outro repositório: `janeiaraujo/jarvis-android` (Kotlin e Compose). Ele não é uma interface deste servidor: roda sozinho no telefone, com o Firestore do projeto `jarvis-android-278d4` como único banco.

O estado e as decisões estão na documentação daquele repositório, em `docs/banco-firestore.md` e `docs/fases.md`.
